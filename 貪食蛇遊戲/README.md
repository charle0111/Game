💡 關鍵功能控制說明
為了讓您能輕鬆客製化遊戲，我在程式碼中分別用 💡 【控制顏色】、💡 【控制速度】 與 💡 【分數控制】 標註了對應的區塊。以下是具體的位置與修改方式說明：

1. 控制顏色 (Colors)
所有的顏色都採用了 CSS 變數進行統一管理，並在 JavaScript 中動態讀取，以確保畫布繪製與網頁外觀色彩完美一致。

CSS 變數定義區（第 9 行至第 19 行）：
css


:root {
    --bg-color: #0d0e15;       /* 遊戲網頁的深色背景 */
    --card-bg: rgba(20, 21, 33, 0.85); /* 遊戲面板的半透明玻璃效果背景 */
    --neon-glow: #00f0ff;      /* 主題霓虹藍色（邊框與發光效果） */
    --snake-head: #00ff88;     /* 蛇頭的亮綠色 */
    --snake-body: #00cc6a;     /* 蛇身的綠色 */
    --food-color: #ff0055;     /* 食物的亮粉紅色 */
    --text-color: #ffffff;     /* 主要文字顏色 */
    --text-muted: #8f9cae;     /* 次要文字顏色 */
}
您只需更改底下的十六進位代碼（例如將 --food-color 改為 #ffaa00 橘色），即可改變遊戲的霓虹配色。
JavaScript 繪圖取值區（第 247 行至第 253 行）： 在 colors 物件中動態抓取 CSS 變數，用於 Canvas 繪製。
2. 控制速度 (Speed)
JavaScript 變數（第 235 行至第 240 行）：
javascript


// 這個變數代表蛇移動一次的間隔時間（單位為毫秒）。
// 數值越小，蛇移動得越快，遊戲難度越高！
const gameSpeed = 100;
如何修改：如果您想讓蛇走得更快、遊戲更有挑戰性，可以將 100 改為 60 或 80；若想讓速度變慢，可以改為 150。
3. 分數控制 (Score)
分數的計算、最高分儲存以及畫面顯示分佈在以下幾個地方：

HTML 顯示結構（第 167 行至第 176 行）： 使用 id="score" 和 id="highScore" 標記當前分數與歷史最高分數的顯示區域。
分數變數初始化（第 225 行）： let score = 0; 初始化目前得分。
讀取與寫入最高分數（第 226 行與第 314 行）： 使用瀏覽器內建的 localStorage 儲存最高分，即使重新整理網頁，最高得分紀錄也不會消失。
吃到食物加分（第 362 行至第 374 行）：
javascript


if (head.x === food.x && head.y === food.y) {
    score += 10; // 每次吃到食物加 10 分
    scoreEl.textContent = formatScore(score);

}
如何修改：如果您想改變每次得分的分值，可以直接修改 score += 10 中的數值。
🎮 遊戲額外亮點與操作
質感設計：採用深色背景、微發光的霓虹陰影、格線效果以及圓角蛇身，展現出復古街機科技感。
流暢操作：支援鍵盤方向鍵（↑ ↓ ← →）與 W A S D 進行控制，並防範了直接反向折返導致自殺的誤觸。
暫停功能：遊戲進行中隨時可以按下 空白鍵 (Space) 或點擊按鈕來暫停/繼續遊戲。
網頁音效：特別利用瀏覽器內建的 Web Audio API 即時合成電子音效（吃到食物時發出清脆的 Beep 高音，遊戲結束時發出低沉漸降的 Buzz 音效），無須載入任何外部音訊檔案，運作快速且流暢。

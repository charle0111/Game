🎨 遊戲大廳首頁 (index.html) 的設計特色與細節
這是一個極具科幻氛圍的 「霓虹電子遊戲廳 (Neon Cyber Arcade)」 大廳頁面：

雙卡片式設計：
  貪食蛇 (Neon Snake)：卡片使用綠色發光霓虹，並附帶動態蛇形 SVG 圖示。
  彈磚塊 (Neon Breaker)：卡片使用藍色與粉色交織霓虹，並附帶彈磚塊與擋板 SVG 圖示。
  卡片在滑鼠懸停時會有向上懸浮（translateY(-8px)）、霓虹發光暈影放大、以及圖示旋律縮放的酷炫動效。
大廳專屬復古音效 (Web Audio API)：
  開機旋律：當您在網頁內首次點擊或按任意鍵時，會流暢播放一段清脆復古的 8-bit C Major 9 琶音開機旋律。
  懸停回饋：當滑鼠滑過不同的遊戲卡片時，會有微弱而厚實的低頻 retro click 聲。
  投幣確認：當您點擊任一款遊戲的「進入遊戲」時，會播放經典的 「街機雙音投幣聲」，隨後才進行流暢的頁面跳轉！
